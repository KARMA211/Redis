NETWORKING FROM A PROMGRMAMMERS PERSPECTIVE 

1>Layer of small ,descrete messages (ip)
    Lowest layer is packet based . the ability to assemble packets into application layer is 
    provided by higher layer , usually TCP.

2> Layer of Multiplexing (Port Number)
    The next layer of IP ( UDP OR TCP ) adds a 16-bit port number to distinguish btw different apps.
    Each app claims a unused local port number before it can send or recive data . 
    computer uses the 4-tuple to identify a flow of informatio : (srs_ip,srs_port,dst_ip,dst_port)


3> Layer of reliable and ordered bytes (TCP)
    TCP provides a layer of reliable and ordered bytes on top of IP packets 

3> TCP/IP Model 
    Higher	    TCP             	Reliable & ordered bytes
    ↕	        Port in TCP/UDP	    Multiplex to programs
    Lower	    IP	                Small, discrete messages




NOTE -> the only thing we only need from the IP layer is the source and destination address 
        IP , post , TCP/UDP are the concepts we wil be dealing with .
